# 기능 명세

Windows 단일 화면에서 제목 입력, 추가 버튼과 할 일 목록을 표시한다. 각 항목에는 완료 체크박스와 삭제 버튼이 있다.

## 입력과 목록

- 제목의 앞뒤 공백을 제거하며 빈 입력은 거부한다.
- 버튼과 Enter는 같은 추가 처리를 사용한다. 정상 추가 후 입력창을 비운다.
- 같은 제목을 허용하고 ID로 구분한다.
- 생성 순서를 유지하며 완료·미완료 항목을 함께 표시한다.
- 빈 목록에는 입력 안내를 표시한다.

## 완료와 삭제

체크박스는 완료·미완료 상태를 전환하고 완료한 제목에는 취소선을 표시한다. 완료 항목을 자동 삭제하지 않는다.

삭제는 해당 ID의 항목만 제거한다. 없는 ID의 삭제·완료 변경은 다른 항목에 영향을 주지 않는다.

## 상태

목록은 Riverpod으로 관리한다. 파일이나 서버에 저장하지 않으므로 앱을 종료하고 다시 실행하면 빈 목록으로 시작한다. 모델과 변경 메서드는 [상태 API](state_api.md)에 있다.
